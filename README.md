# BetterUX

BetterUX (Better User eXperience) is a client-side mod for 4D Miner 0.2.1.4 that improves various parts of the interface, controls, and general gameplay experience.

Made using the [4DModding framework](https://4d-modding.com/) and generated from the [official mod template](https://github.com/4D-Modding/4dmod-example).

## Main Menu

- Reorganized settings menu
- Fixed window resize bug
- Automatic categorization for modded settings
- Added world settings buttons
- Added server list
- Optimized background world loading
- Added configurable background world render distance

## Keybinds and Controls

- Inventory sorting on `R` (supports 4DKeybinds)
- Offhand switching on `F` (supports 4DKeybinds)
- Hotbar switching using number keys
- Hotbar cycling using `<` and `>` (supports 4DKeybinds)
- Block picking with `Ctrl + MMB`
- Improved inventory drop behavior
- Fast crafting shortcuts:
  - `Ctrl` = craft 10
  - `Shift + Ctrl` = craft 50
  - `Shift` = craft all
- Context-sensitive item dropping from inventory
- Configurable crafting counts through `config.json`

## Game UI

- Recipe search field
- Collected item popups with customizable settings
- Health counter above health bar
- World save button without exiting the world
